# Numerical environment and comparison families

The fixed local profile is Python 3.12.3, NumPy 1.26.4, SciPy 1.15.2, scikit-learn 1.6.1 and MKL 2023.1, with one numerical thread. Single-route controls must be checked before fusion; saved server and local text-only OOF controls are distinguished. The adopted local baseline is defined in LOCAL_LINEAGE_ADOPTION.md.

The six prosody coordinates use PCG64 seed 2026110502 and the max-standardized-deviation simultaneous family rule. Descriptive prosody uses all 15 variables, unweighted summaries and design-weighted means/differences, seed 2026110503, 10,000 shared whole-day draws and pointwise intervals. Missing observed values are not imputed. Each original local calculation used one process, a 600-second budget and 4 GiB budget, with measured RSS rather than an OS hard memory cap.
